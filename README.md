# picavet-it.com

Portfolio and CV site of Kenny Picavet (Picavet IT), built with [Astro](https://astro.build) and Tailwind CSS.

## Develop

```sh
npm install
npm run dev      # http://localhost:4321
npm run build    # production build into dist/
npm run preview  # serve the production build
```

## Deploy

Every push to `main` is built and deployed by Netlify (see `netlify.toml`).
Pushes to other branches get a deploy preview.
